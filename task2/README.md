# Task 2 — Rainfall Probability Prediction

- `data_prep/`: shared dataset preparation and documentation for all classifiers.
- `Model_GBT/`: GBT training records, tuning results and a self-contained final-test notebook.
- Shared data remain in `task2/data/` or external storage; do not duplicate them in model directories.

See the [GBT workflow](Model_GBT/README.md). Existing training records are in `Model_GBT/notebooks/task2_gbt_training.ipynb`; after model selection, run `Model_GBT/notebooks/test_gbt_final.ipynb` for independent evaluation.

Root-level `outputs/` contains Task 1 analysis artifacts and is separate from model outputs.
